# Security

If you find a vulnerability in Jadarit, please tell us privately rather than in
a public issue, so it can be fixed before it is widely known.

- **Preferred:** [report it through GitHub](https://github.com/Jadarit-com/jadarit-releases/security/advisories/new).
  Only you and the maintainers can see the report.
- **Or by email:** support@jadarit.com, with "Security" in the subject.

Please include the version (from `curl -s http://localhost:9001/health`), what
an attacker can do, and how to reproduce it. We aim to reply within two working
days, and to keep you informed until it is fixed. We are happy to credit you in
the release notes if you would like.

Security fixes are published as new releases in this repository. Only the
latest release receives them, so please keep your installs up to date.
